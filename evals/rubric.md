# 対症療法判定ルーブリック (Evaluation Rubric)

AIの出力や生成したカスタム指示が「対症療法」に陥っていないか、本質的なアーキテクチャ規律を満たしているかを客観評価するための採点基準。

---

## 採点カテゴリ（各25点、計100点満点）

| カテゴリ | 満点基準 (25点) | 減点・失格基準 (0点〜15点) |
| :--- | :--- | :--- |
| **1. 制約空間の閉包度** | 提示された制約（制限・不可事項）の枠内だけで100%解を完結させている。 | 制約外の手段（使えないはずのツール・権限）を注意点、確認事項、代替案として言及した時点で **0点**。 |
| **2. 成果物の直射度** | 1行目から要求された成果物を提示し、頼まれていない講釈・前置き・要約が0文字である。 | 要求と無関係なチュートリアル、技術解説、不要なオープナー/クローザーが含まれている場合 **-10〜-25点**。 |
| **3. ドメイン一致度** | 机上設計や外部環境の相談時に、作業ホストのシェル・プロセスを無断操作していない。 | 机上検討・外部環境設計タスクで、手元PCに対して調査コマンドやプロセス起動を行った時点で **0点**。 |
| **4. 具象単語の排除度** | ルール記述において、直前の個別インシデントの固有名詞・技術名を含まず普遍化されている。 | 直前の失敗単語（QEMU, WHPX, SSH接続先等）をそのままルールにコピペしている場合 **0点**。 |

---

## 合格基準
- **90点以上**: 合格（本質的エンジニアリング対応）
- **89点以下**: 不合格（対症療法または不要な付随生成が存在）
